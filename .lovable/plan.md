# Akashganga corporate homepage

## Scope
Build the homepage only as a polished, responsive client-approval concept for Akashganga Constructional Machines.

## Implementation
- Establish the white, sky-blue, dark-blue and slate design system in global styles, with Plus Jakarta Sans headings and Inter body text.
- Create a typed content file for machines, statistics, applications, contacts, navigation, network locations, news, and swappable image placeholders.
- Build reusable sections for the top bar, sticky responsive header, hero, statistics, company overview, machines, technology, process, applications, comparison, certificates, clients, network/news, enquiry form, footer, and WhatsApp action.
- Use fixed-ratio, accessible image placeholders throughout and keep every unavailable fact explicitly marked in square brackets.
- Add subtle Framer Motion reveal effects, once-only number counters, restrained card/image hover states, reduced-motion support, and a keyboard-accessible mobile menu and machine dropdown.
- Implement client-side enquiry form validation and a clear success state without inventing a delivery service or database.
- Add homepage-specific SEO and social metadata.

## Quality checks
- Verify the page at 375px, 768px, 1024px, and 1440px widths.
- Check navigation, mobile menu, enquiry validation/success, visible focus states, text wrapping, section spacing, and non-overlap.
- Confirm the latest preview build has no errors and that the page stays white except for subtle tinted bands and the permitted dark footer.
